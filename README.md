# Config File Generator

Portal sencillo en Flask para generar configuraciones de dispositivos de red Huawei.

## Requisitos

- Python 3
- Flask (`pip install Flask`)

## Uso

Ejecute `python app.py` y abra `http://localhost:5000` en su navegador.
Complete los formularios para obtener el texto de configuración o descargar el archivo `config.cfg`.

Este proyecto es un punto de partida y puede ampliarse para soportar más tipos de dispositivos y parámetros.
